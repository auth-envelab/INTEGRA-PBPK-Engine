# Release Notes

## Version 0.6.1

Package metadata, MIT licensing, and documentation updates.
No changes to the scientific PBPK calculations.

## Version 0.6.0

Initial release of INTEGRA-PBPK-Engine.

This version introduces a unified R interface with 13 public functions covering:

- Model and parameter exploration.
- Forward PBPK simulation.
- Calibration and evaluation results.
- Sensitivity and uncertainty analysis.
- Exposure reconstruction.
- Model equations and compartment diagrams.

PFBS is the first supported chemical. Additional chemical models are planned for future releases.

See the [Getting Started](01_Getting_Started.md) guide for installation and initial usage.
